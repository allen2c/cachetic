# Implement Postgres backend extension

## Description

Add a PostgreSQL cache backend at `cachetic/extensions/postgres.py` using
`peewee` ORM with `psycopg[binary]` driver. Follows the same adapter pattern
established in CAC-007.

### Table schema

```sql
CREATE TABLE IF NOT EXISTS {table_name} (
    name       TEXT    PRIMARY KEY,
    value      TEXT    NOT NULL,
    expires_at BIGINT
);
```

- `value` is `TEXT` because Data URL strings (from CAC-009) are ASCII text.
- `expires_at` is a Unix timestamp (seconds). `NULL` = no expiration.
  Note: the `CacheProtocol` API `ex` parameter is duration (seconds);
  the adapter converts to timestamp internally (`time.time() + ex`),
  same pattern as `MongoCache`.

### Connection URL format

```
postgresql://user:pass@host:5432/mydb?table=my_cache_table
```

Table name extracted from `?table=` query parameter. Default table name
if not specified: `cachetic_cache`.

### Expiry behavior

On `get()`: check `expires_at` against current time. If expired, delete
the row and return `None` (lazy expiration, same as MongoCache).

### Optional dependency

Already defined in `pyproject.toml`:
```toml
postgres = ["peewee", "psycopg[binary]"]
```

Install via: `pip install cachetic[postgres]`
