# CAC-004: Reuse Zstd Compressor/Decompressor as module-level singletons

## Description

`compress_auto` and `decompress_auto` in `cachetic/utils/compression.py` instantiate
a new `ZstdCompressor(level=3)` (line 66) and `ZstdDecompressor()` (line 107) on every
call. Both objects are thread-safe and reusable — creating them once at module level
eliminates per-call allocation overhead.

## Acceptance Criteria

- [ ] `ZstdCompressor(level=3)` is created once at module level (only when `HAS_ZSTD` is True)
- [ ] `ZstdDecompressor()` is created once at module level (only when `HAS_ZSTD` is True)
- [ ] `compress_auto` and `decompress_auto` reference the shared instances
- [ ] Existing compression/decompression tests continue to pass
- [ ] No behavioral change in output

## Action Log

### 2026-03-18
Created `_ZSTD_COMPRESSOR` and `_ZSTD_DECOMPRESSOR` as module-level singletons in `cachetic/utils/compression.py`.
`compress_auto` and `decompress_auto` now reference the shared instances.
