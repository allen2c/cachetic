# CAC-005: Cache `_is_bytes_type` check at instance init

## Description

`_validate_any` and `_dump_any` in `cachetic/__init__.py` (lines 191, 227) both
evaluate `inspect.isclass(self.object_type._type) and issubclass(self.object_type._type, bytes)`
on every get/set call. The result is invariant over the instance lifetime.

Compute this once during model validation and store it as `self._is_bytes_type` to
avoid repeated introspection on the hot path.

## Acceptance Criteria

- [ ] A `_is_bytes_type: bool` field (or equivalent) is computed once after model init
- [ ] `_validate_any` and `_dump_any` use the cached value instead of `inspect.isclass` / `issubclass`
- [ ] All existing type tests (`test_object_types.py`, `test_readme_usages.py`) continue to pass
- [ ] No behavioral change

## Action Log

### 2026-03-18
Added `_is_bytes_type: pydantic.PrivateAttr(default=False)` to `Cachetic`, computed once in `validate_after_init`.
`_validate_any` and `_dump_any` now use `self._is_bytes_type` instead of `inspect.isclass`/`issubclass`.
