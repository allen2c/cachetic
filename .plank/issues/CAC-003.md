# CAC-003: MongoCache — Add tests for connection reuse behavior

## Description

The connection registry (CAC-001) and index deduplication (CAC-002) introduce
module-level state that must be tested for correctness. Add tests to
`tests/test_mongo_cache.py` covering:

- Two `MongoCache` instances with the same URL share one `MongoClient`
- Two `MongoCache` instances with different URLs get separate clients
- `create_index` is called only once for repeated same-collection instantiations
- Registry and index set can be cleared for test isolation

## Acceptance Criteria

- [ ] Test: same URL → same `MongoClient` identity (`is` check)
- [ ] Test: different URL → different `MongoClient` instances
- [ ] Test: `create_index` call count is 1 for two instances on the same collection (mock or spy)
- [ ] Test: `create_index` call count is 2 for two instances on different collections
- [ ] Tests clean up module-level state (`_client_registry`, `_ensured_indexes`) in teardown

## Action Log

Added 4 tests to `tests/test_mongo_cache.py`:
