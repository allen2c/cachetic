# CAC-001: MongoCache — Share MongoClient across instances via connection registry

## Description

`MongoCache.__init__` creates a new `pymongo.MongoClient` on every instantiation
(`cachetic/extensions/mongodb.py`, line 67). When multiple `Cachetic` instances use
the same MongoDB connection string (common in applications with several collections
on the same cluster), each triggers an independent SASL auth handshake (~180–333ms)
and maintains a separate connection pool.

Introduce a module-level connection registry keyed by the normalized connection URL.
When a `MongoCache` is instantiated, check the registry first; create a new client
only if no existing client matches.

## Acceptance Criteria

- [ ] A module-level `_client_registry: Dict[str, MongoClient]` maps connection strings to shared clients
- [ ] `MongoCache.__init__` reuses an existing client when one exists for the same URL
- [ ] A new client is created and registered only when no match exists
- [ ] Log message distinguishes "Reusing existing MongoClient" from "Created new MongoClient"
- [ ] Existing `MongoCache` public API (`set`, `get`, `delete`) is unchanged
- [ ] `self.client` still references the (possibly shared) `MongoClient` instance

## Action Log

### 2026-03-18
Added module-level `_client_registry: Dict[str, MongoClient]` in `cachetic/extensions/mongodb.py`.
`MongoCache.__init__` now checks registry before creating a new client. Log messages distinguish reuse vs creation.
