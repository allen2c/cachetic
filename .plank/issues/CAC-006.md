# CAC-006: Guard debug log calls to avoid eager `pretty_repr` evaluation

## Description

Several `logger.debug(f"... {pretty_repr(...)}")` calls in `cachetic/__init__.py`
(lines 133, 182, 217) eagerly evaluate `pretty_repr()` via f-string interpolation
even when the DEBUG log level is not enabled. `pretty_repr` from `rich` is non-trivial
and should not execute on every cache operation in production.

## Acceptance Criteria

- [ ] Debug log calls in `Cachetic.get`, `Cachetic.set`, and `_loads_any` are guarded with `logger.isEnabledFor(logging.DEBUG)` or use lazy `%s` formatting
- [ ] `pretty_repr` is only called when DEBUG logging is active
- [ ] No change to log output when DEBUG is enabled

## Action Log

### 2026-03-18
Wrapped `logger.debug` calls in `Cachetic.get` and `Cachetic.set` with `logger.isEnabledFor(logging.DEBUG)`.
Changed `logger.warning` in `_loads_any` to use lazy `%s` formatting instead of f-string with `pretty_repr`.
