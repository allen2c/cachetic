# Unify backend architecture with CacheProtocol adapters

## Description

Currently DiskCache and Redis are handled inline in `Cachetic.__init__.py`
while MongoDB lives under `extensions/`. This ticket unifies all backends
behind explicit `CacheProtocol` adapter classes so that:

- Every backend is a first-class `CacheProtocol` implementation.
- `Cachetic.cache` return type becomes `CacheProtocol` (no Union of externals).
- `Cachetic.cache_url` accepts `str | pathlib.Path | CacheProtocol` — raw
  third-party instances (e.g. `redis.Redis`, `diskcache.Cache`) still work
  via structural subtyping (positional-arg coincidence is intentional).

### URL routing (in `Cachetic.cache` property)

| Scheme prefix    | Adapter                                |
|------------------|----------------------------------------|
| `redis://`       | `cachetic.extensions.redis.RedisCache` |
| `mongo://` etc.  | `cachetic.extensions.mongodb.MongoCache` |
| `postgresql://`  | `cachetic.extensions.postgres.PostgresCache` |
| path / other str | `cachetic.extensions.disk.DiskCache`   |

### CacheProtocol update

Use positional-only parameters (`/`) so parameter-name differences across
third-party backends become irrelevant for structural subtyping:

```python
class CacheProtocol(typing.Protocol):
    def set(self, name: str, value: bytes, ex: int | None = None, /) -> None: ...
    def get(self, name: str, /) -> bytes | None: ...
    def delete(self, name: str, /) -> None: ...
```

### Backward compatibility

- `Cachetic(cache_url=redis.Redis(...))` continues to work.
- `Cachetic(cache_url=diskcache.Cache(...))` continues to work.
- `Cachetic(cache_url="redis://...")` continues to work.
- `Cachetic(cache_url=pathlib.Path(...))` continues to work.

## Acceptance Criteria

- [ ] `cachetic/extensions/disk.py` exists with `DiskCache(CacheProtocol)`
- [ ] `cachetic/extensions/redis.py` exists with `RedisCache(CacheProtocol)`

- [ ] `CacheProtocol` uses positional-only params (`/`)
- [ ] `Cachetic.cache` property return type is `CacheProtocol`
- [ ] `Cachetic.cache_url` type is `str | pathlib.Path | CacheProtocol`
- [ ] Passing raw `redis.Redis` / `diskcache.Cache` instances still works
