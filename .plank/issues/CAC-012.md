# Make `rich` a conditional import

## Description

`from rich.pretty import pretty_repr` is a top-level import in
`cachetic/__init__.py`. It is only used inside `logger.debug()` calls
guarded by `logger.isEnabledFor(logging.DEBUG)`.

Replace with a conditional import that falls back to `repr()` when
`rich` is not installed, reducing the hard dependency footprint.

### Approach

```python
try:
    from rich.pretty import pretty_repr
except ImportError:
    pretty_repr = repr  # type: ignore[assignment]
```

Or, since `pretty_repr` is only used in debug-guarded blocks, a lazy
import inside those blocks is also acceptable.

## Acceptance Criteria

- [ ] `cachetic` importable without `rich` installed
- [ ] Debug logging still works with `rich` installed (pretty output)
- [ ] Debug logging gracefully falls back to `repr()` without `rich`
- [ ] `rich` removed from `[project.dependencies]` or kept as optional
