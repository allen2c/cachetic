# Scope `str_or_none` to mongodb optional dependency

## Description

`str_or_none` is a core dependency but only used in one place:
`cachetic/extensions/mongodb.py` line 9. It should not be a required
install for users who never use MongoDB.

### Options

1. **Internalize**: Replace with a simple inline helper
   (`lambda s: s.strip() or None if isinstance(s, str) else None`).
2. **Move to optional**: Keep the import inside `mongodb.py` and remove
   from `[project.dependencies]`.

Option 1 is preferred — one fewer external dependency, trivial function.

## Acceptance Criteria

- [x] `str_or_none` removed from `[project.dependencies]`
- [x] `mongodb.py` still validates URL input correctly
- [x] `cachetic` importable without `str_or_none` installed
- [x] MongoDB tests pass unchanged
