# Make Redis an optional extension

## Description

`redis` is currently a hard dependency imported at the top of
`cachetic/__init__.py`. After CAC-007 introduces `RedisCache` adapter in
`cachetic/extensions/redis.py`, the top-level `import redis` can be removed.

Redis becomes an optional install: `pip install cachetic[redis]`.

### Changes required

1. Remove `import redis` from `cachetic/__init__.py`.
2. Remove `redis` from `[project.dependencies]` in `pyproject.toml`.
3. Add `redis = ["redis (>=5)"]` to `[project.optional-dependencies]`
   (already present — verify).
4. Lazy-import redis only inside `cachetic/extensions/redis.py`.
5. `Cachetic.cache_url` type annotation must not reference `redis.Redis`
   directly — replaced by `CacheProtocol` (from CAC-007).

### Backward compatibility

- Users who have `redis` installed and pass `redis.Redis` instances: works
  via `CacheProtocol` structural subtyping.
- Users who pass `"redis://..."` string: `RedisCache` adapter lazy-imports
  redis; clear `ImportError` message if redis not installed.

## Acceptance Criteria

- [ ] `cachetic/__init__.py` has no top-level `import redis`
- [ ] `redis` not in `[project.dependencies]`
- [ ] `redis` listed in `[project.optional-dependencies]`
- [ ] `cachetic` importable without redis installed
- [ ] `Cachetic(cache_url="redis://...")` raises clear error when redis missing
- [ ] All redis tests still pass when redis IS installed
